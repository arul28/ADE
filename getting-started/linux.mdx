ADE runs on Linux as the same app, brain, and CLI as on macOS and Windows: lanes, agent chat, PRs, terminals, the built-in browser, and phone pairing all work. On a server with no screen you can run [just the brain](/getting-started/connect-machine) instead.

## Install

| | AppImage | `.deb` |
| --- | --- | --- |
| Works on | Most distributions | Debian, Ubuntu and their relatives |
| Updates | Updates itself | ADE tells you a new version exists and links the download |
| Needs root to install | No | Yes |
| Ubuntu 24.04 and newer | Needs one extra step, below | Works as is |

**On Ubuntu 24.04 or newer, pick the `.deb`.** Anywhere else, the AppImage is the easy choice because it keeps itself current.

<Tabs>
  <Tab title="AppImage">
    Download for [x64](https://ade-app.dev/download/linux-x64-appimage) or [arm64](https://ade-app.dev/download/linux-arm64-appimage), then:

    ```bash
    chmod +x ADE-*.AppImage
    ./ADE-*.AppImage
    ```

    The first launch adds ADE to your applications menu, makes `ade://` links open it, and sets up ADE's background brain under `~/.ade`, so the brain keeps running after you close the app and comes back when you log in. If you move the file, open it once from its new place to update the menu entry.
  </Tab>
  <Tab title=".deb">
    Download for [x64](https://ade-app.dev/download/linux-x64-deb) or [arm64](https://ade-app.dev/download/linux-arm64-deb), then:

    ```bash
    sudo apt install ./ADE-*.deb
    ```

    This adds ADE to your applications menu and puts the `ade` command on your `PATH`.
  </Tab>
</Tabs>

Already running the brain on this machine? The desktop app connects to it and leaves it in place.

## If the AppImage will not start

**"ADE cannot start its security sandbox."** ADE's built-in browser opens web pages inside a security sandbox. Ubuntu 24.04 and newer block what an AppImage needs for it, so ADE stops rather than running without one. Install the `.deb`, which is set up for this.

If you accept the risk, you can run without the sandbox:

```bash
ADE_ALLOW_NO_SANDBOX=1 ./ADE-*.AppImage
```

**A FUSE error.** AppImages need FUSE to mount themselves. Install it with `sudo apt install fuse3` (or your distribution's package), or run `./ADE-*.AppImage --appimage-extract-and-run`.

## Saved sign-ins

ADE uses your desktop's keyring, such as GNOME Keyring or KWallet, when it has one, and its own encrypted store when it doesn't.

## What is different from macOS

| Feature | On Linux |
| --- | --- |
| iOS simulator | Runs on a Mac. A Linux window can still use the one on a paired Mac. |
| Global capture gesture | Not available. |
| Apple Music and Spotify playback | Not available. |
| HEIC and HEIF photos | Not converted, so ADE won't attach them. Convert them to JPEG first. |
| Keeping the machine awake | "While I'm away" stops idle sleep on systemd distributions. ADE can't keep it awake with the lid closed. |

Each lane can still have its own [Linux screen](/computer-use/overview) for agents to drive.
