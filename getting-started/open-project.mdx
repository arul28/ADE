Use **Open Repository** on the welcome screen or press `Cmd+O`. Choose the root of a Git repository. If you choose a subfolder, ADE tries to find the repository root automatically.

## What ADE creates

On first open, ADE creates a local `.ade/` directory:

```text
.ade/
  ade.db
  worktrees/
  artifacts/
  cache/
  secrets/
```

This directory contains local runtime state, lane worktrees, transcripts, proof, and credentials. It should normally be gitignored.

<Warning>
Do not commit `.ade/` wholesale. It contains machine-local paths and state. If your project needs shared ADE defaults later, use the project configuration flow rather than committing local secrets or runtime files.
</Warning>

## First setup

The setup flow checks the basics:

- Git is installed.
- At least one AI provider is ready.
- GitHub is available if you want PR management.
- Linear is available if your team uses it.
- Optional mobile pairing can be configured later in Settings.

You can skip setup steps and return to them from **Settings**.

## After opening

Create a lane before running your first agent. That keeps your primary checkout clean and gives the task its own branch and worktree.
