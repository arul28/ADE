Use **Open Repository** on the welcome screen or press `Cmd+O` (`Ctrl+O` on Windows). Choose the root of a Git repository, or clone one straight from GitHub. If you pick a subfolder, ADE finds the repository root automatically.

## What ADE creates

On first open, ADE creates a local `.ade/` directory:

```text
.ade/
  ade.db
  worktrees/
  artifacts/
  cache/
  secrets/
```

This holds local runtime state, lane worktrees, transcripts, proof, and credentials. It should normally be gitignored.

Your repository root becomes the **primary lane** — it always exists and is edit-protected. Every other lane you add is a separate worktree under `.ade/worktrees/`, so agent work never touches your main checkout until you choose to merge it.

If the folder you pick is itself a Git worktree of another repository, ADE recognizes that and offers to open it as a lane in the owning project instead of creating a duplicate project. See [Repos and worktrees](/lanes/repos-and-worktrees).

<Warning>
Do not commit `.ade/` wholesale. It contains machine-local paths and state. If your project needs shared ADE defaults later, use the project configuration flow rather than committing local secrets or runtime files.
</Warning>

## First setup

The setup flow checks the basics:

- Git is installed.
- At least one AI provider is ready.
- GitHub is available if you want PR management.
- Linear is available if your team uses it.
- Optional mobile pairing can be configured later in Settings.

You can skip any step and return to it from **Settings**.

## After opening

Create a lane before running your first agent. That keeps your primary checkout clean and gives the task its own branch and worktree.
