ADE 1.2.100 makes chats, page tabs, project switching, and the web client faster, and adds per-account control of Claude subagent prompt caching.

## Performance

- Chats and page tabs switch when you press them, with less rendering work during navigation (#1583).
- Faster chat streaming, web client startup, project switching, and file watching (#1576).

## Claude accounts

- Configure subagent prompt caching per Claude account. The one-hour cache is opt-in rather than enabled by default (#1582).
