ADE 1.2.132 shows the ADE Cloud iPhone's minutes and idle stop everywhere and tells the chat when it starts and stops, lets ADE's server move, free and copy cloud computers with no machine of your own, and stops the brain freezing on projects with many lanes.

## New

- The ADE Cloud iPhone shows its model, time on, minutes left and idle stop in the pane, with Keep on in its last 90 seconds, and as a top bar icon while it runs (#2426).
- A chat whose agent starts the ADE Cloud iPhone is told when it starts and when it stops, and why (#2426).
- ADE's server moves, frees and copies an ADE Cloud computer from every client, with no machine of your own online (#2400, #2404).
- An ADE Cloud lane kept without a computer opens its own page, with New computer and Delete (#2407, #2424).

## Improved

- Agents drive the ADE Cloud iPhone faster: a machine with an older ADE says to update it, screenshots retake a blank first frame and print a cite line, and the skill names the quick path (#2426).
- A watched move or free goes on in seconds, and a computer that just woke frees on the first try (#2401, #2413).
- Claude downloads account skills before the first chat, so the second chat reads the prompt cache (#2416).
- The resource check reuses a calm process list while the pressure chip shows (#2403).
- A computer the server made lists under its name, and `ade lanes create --machine cloud` shows the launch (#2406, #2420).

## Fixed

- The brain no longer freezes on projects with many lanes, a freeze names its cause, and CLI messages no longer stick in a queue (#2421).
- A new chat keeps the screen when an earlier send finishes or a sent chat's link opens late (#2423, #2425).
- A chat snapshot never comes back empty for a chat with history (#2419).
- A remote Windows update can no longer hang and leave the PC offline (#2394).
- A free right after work ends is no longer refused, and the phone follows a move to its new computer (#2405).
- ADE Web opens Connections at once, reads Tools again after a lost link, and never hides Projects (#2415).
- Agents never make an ADE Cloud computer on their own (#2424).
- Live Sentry issues from v1.2.131 are fixed, and normal states stop reporting as errors (#2402, #2412, #2414, #2417, #2418).
- The ADE Cloud iPhone pane says why a held free plan has no minutes, and the switch-device bar wraps instead of one word per line (#2411, #2426).

## iOS

- Pulling Lanes or Work lists a cloud computer made elsewhere since the last look (#2422).
- ADE Cloud lanes kept without a computer show with New computer and Delete (#2407).
- The photo picker, device-key signing and live drops no longer slow the main thread (#2410).
