ADE 1.2.97 brings a widget-based dev home with a Browser tab and Apple Music, instant chat comments, automation test runs, and a round of chat and Focus polish.

## Home

- ADE dev home: one chat system, a Browser tab, a widget home, Apple Music, and Now Playing (#1544).

## Work

- Chat comments show instantly, pinned views get pushed events, and remote event traffic is halved (#1539).
- Computer-use rows name the app, proof shows inline, and proof counts open a filtered drawer (#1553).
- Declining a question stops the model instead of letting it choose (#1545).
- A chat settles when its auto-linked PR merges (#1543).
- Linear agent step lines are readable, with no phantom busy subagents or duplicate history rows (#1551).

## Automations

- Test runs, kept drafts, notification links to run-made items, and older-machine warnings (#1546).

## Fixes

- Dictation downloads no longer time out and the model warms after install; the issue picker no longer reloads in a loop (#1540).
- A running shell no longer keeps a Focus lane folded, and the Focus grid empty state is clearer (#1552, #1542).
- The brain watchdog logs short sleeps as suspend gaps instead of stalls (#1550).
