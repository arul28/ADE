One computer-use contract, folded chat turns, a faster mobile thread engine, lanes from the composer, and Claude Opus 5.5.

---

## Computer use

- **One contract for computer use.** App Control works at the Mac Desktop level, each lane stays isolated, and a setting controls browser access.

## Chat

- **Finished turns fold.** A chat shows one task list, and every client shows the sources an agent used.
- **Steers show at once.** Subagent reports no longer repeat.

## Work

- **Each chat's activity comes from its tool calls.**
- **The Work board shows the chats of every machine.**
- **Configure a new lane from the chat composer.**
- Session cards no longer show the model name.

## PRs

- **A PR opened as a lane gets a lane name** and reads as a lane.
- Drifted PRs show, and a failing CI stretch is announced once.
- Cursor automations start in full-auto.

## Lanes

- Orphan external lanes delete cleanly, and you can reveal their folders.

## Apple devices

- The tools card can claim a device.

## Providers

- **Claude Opus 5.5** (`claude-opus-5-5`) is the default Opus model, with medium effort and Fast mode. Opus 5 stays selectable. Saved Opus 4.8 ids resolve to Opus 5.
- Claude Agent SDK 0.3.280.

## iOS

- **A new thread engine** matches desktop turns, and sync replies stay bounded in size.
