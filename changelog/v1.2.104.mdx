ADE 1.2.104 adds Meta Muse Code as a provider, steadies Windows, and makes chats resume properly after an update.

## Providers

- Meta Muse Code is a first-class provider, in chat and as a tracked CLI, with its own Settings page (#1614).

## Updates

- After an install, ADE waits for the update to finish before reopening your projects, so the chats you asked to resume come back (#1618).

## Windows

- Model lists stay live, browser commands no longer time out early, and the last open chat reopens (#1612).

## Apple

- Inspect selects the element you click in the Apple tool (#1619).

## Reliability

- Error tracking now covers every surface (desktop, web, workers and iOS), with secrets and content scrubbed (#1612).
