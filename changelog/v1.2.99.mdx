ADE 1.2.99 adds chat drafts and scheduled sending, improves context compaction, and fixes chat naming and Home layout.

## Chat

- Save drafts, schedule messages, and keep reusable prompts across desktop, web, CLI, and iOS (#1572).
- Configure automatic compaction with clearer context usage and quieter transcript dividers (#1570).
- Chat naming uses the chat's own account and preserves existing names when naming fails (#1571).

## Home

- Fixed the add-widget crash on macOS 27 and improved centred grid spacing and row alignment (#1569).
