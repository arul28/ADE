Themes, Devin as a provider, OpenCode 2.0, every machine in every tab, demo videos in proof, and one Work list on mobile.

---

## Themes

- **The ADE theme engine** comes with a library of themes and a gallery.
- **An advanced theme customizer** edits every color.
- **Import and export themes,** including VS Code themes.

## Providers

- **Devin is a first-class provider.**
- **ADE uses OpenCode 2.0.** Steering is truthful, OpenCode has its own data home, child permissions work, and turns are bounded.
- The Grok CLI version is monitored, with a one-click update.
- OpenCode Go limits come from the OpenCode console login.

## Machines

- **Every tab shows every machine,** and the start screen has a new design.
- **New lanes balance across connected machines.**
- The clean default branch pulls automatically on open and in the background.

## Chat

- Large pastes fold into a text attachment.
- Session rows mark unsent drafts and queued messages.
- An ACP failure card shows the agent's stderr.
- Collapsed one-line previews drop Markdown.

## Usage

- **Live quota pools across machines,** with an environment filter.
- Claude banked resets show, and you can redeem them.
- The header controls have a new order, and settings control usage visibility.

## Proof

- **Demo videos** use one H.264 decoder.
- Proof shows in answers, in the drawer, and in PRs.

## PRs and diffs

- The PR code tab has a changed-file tree.
- Sort pull requests by "blocked on me".
- The diff viewer has an ignore-whitespace toggle, and whitespace-only lines keep the correct order.

## Apple devices

- The device view has a foldable Duo hinge mode, and the device rail shows hardware buttons.
- Simulator cleanup deletes stale devices of other projects.

## Desktop

- The changelog shows after an update, and project tabs open again.
- Windows editor discovery finds editors outside PATH.

## iOS

- **One Work list across machines,** faster threads, and host fleet support.
- Slash commands come from the host.

## CLI

- `ade chat models` lists full model ids and providers.
