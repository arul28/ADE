ADE 1.2.107 lets you fork a chat to another provider on another machine, and fixes stale pull requests on the primary lane.

## Chat

- Fork a chat to a different provider on a different machine (#1641).
- Provider checks run quietly, and model controls are back (#1623).

## Lanes

- The primary lane stops showing old pull requests once it is back on main, on desktop and iOS (#1639).

## Work

- The Focus grid stays live with the sidebar collapsed (#1640).

## Projects

- Moving a project picks the check agent's model in place, shows its banner only in the moved project, and keeps Codex trust (#1638).
- Simulator cleanup stays on its original project (#1596).

## Release

- Release tags survive cancelled or flaky CI on notes-only commits (#1636).
