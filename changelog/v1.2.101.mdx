ADE 1.2.101 makes switching between loaded projects faster.

## Project navigation

- Loaded project tabs switch when you press them, reducing the measured warm switch time from 136–137 ms to 44–51 ms (#1585).
- Dragging a background project tab brings it to the front. Detaching a tab waits for its pending project switch before closing it in the source window (#1585).
