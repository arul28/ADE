ADE 1.2.93 brings webhook automations, Focus and stall detection in Work, a visual design refresh, and Mac Desktop input that leaves your pointer alone.

## Automations

- Webhook automations: any service that can call a URL can start an agent, and secrets can be set from chat (#1498).

## Work and chats

- Focus and the Focus grid, plus stall detection for every provider (#1494).
- The stall banner measures silence from the transcript, not a frozen summary (#1496).
- Account moves keep the real Claude thread, and a stale cache can't pin agents as running (#1490).

## Design

- Visual refresh: home dashboard, picture backgrounds, and redesigned Settings (#1497).

## Lanes and computer use

- Moving unstaged changes to a new lane runs on a pinned lane's own machine (#1492).
- Mac Desktop clicks, scrolls, and drags inside lane apps without moving your pointer (#1493).
