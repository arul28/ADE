## Fixes in this branch

1. **A failed turn's storage write skipped the rest of the `done` event**
   (`01a1e5ec-61eb`). `markLastTurnFailed` is a database write; a drive that
   stopped answering threw inside `emitChatEvent`, so the `done` event did not
   reach the transcript or the app, the scheduled-work record was skipped, and
   the send path rejected with no handler. The verdict write is now best effort
   and logged (`agent_chat.turn_verdict_write_failed`).
2. **Kimi without Git for Windows** was filed as a provider issue
   (`01a1c6e9-bde6`, 3 users). It is the person's setup and the message says
   what to install; it is now an expected answer (`expectedFailure.ts`). The
   provider card still shows it.
3. **Telemetry: `rpc_tool_failed` named no cause.** 445 brain action failures
   on 1.2.129 in 14 days are `rpc_tool_failed` with no way to tell which code
   threw (`git.getOriginRemote`, `diff.getChanges`, `pr.getGithubSnapshot`,
   `chat.listThreadComments`, 12 to 22 users each). `ade_brain_action_failed`
   now carries `brain_frame`: the brain's own top frame as `function:line`
   (or `<anonymous>:line`), no file name and no path, checked by shape in the
   analytics policy (`reliabilityTelemetry.ts`, `productAnalyticsPolicy.ts`,
   `registerIpc.ts`).

Fixed in #2343 (`d45f5f0f8`), not repeated here: the chat create crash with no
provider (`01a1ebd5-486c`), `pr.land` with no arguments (`01a1e74c-273b`), and
saved logins for a closed tab (`01a1e7fe-f42b`).
