simulator. The audit uses the real iOS app on an iPhone 17 simulator, connected

the simulator with visible UI evidence. Rows marked `prompt-only` were opened to
the preflight/prompt boundary. Rows marked `deferred` name the concrete fixture,
external-boundary, or unavailable-service reason that blocked safe execution in
this pass.
