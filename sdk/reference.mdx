## `createAdeChat(options)`

```ts
function createAdeChat(options: CreateAdeChatOptions): Promise<AdeChatClient>
```

| Option | Type | |
|---|---|---|
| `home` | `string` | Required. Isolated state root. Created if missing. |
| `binaryPath` | `string` | Pin an `ade` binary. Skips every later resolution step. |
| `runtimeNodeModules` | `string` | `ADE_RUNTIME_NODE_MODULES`. Required with `binaryPath` when the native modules are not beside the binary. |
| `runtimeRoot` | `string` | `ADE_RUNTIME_ROOT`. Defaults to the parent of `runtimeNodeModules`. |
| `allowDownload` | `boolean` | Default `true`. `false` throws `runtime_unavailable` instead of reaching the network. |
| `channel` | `string` | Downloader channel: `latest` (default) or a release tag. |
| `logger` | `(line: string) => void` | Sidecar / client log sink. |
| `instructions` | `string \| { mode, text }` | Default instructions for every thread. A per-thread value replaces it. |
| `mcpHeaders` | `(key, serverName) => Record<string, string> \| undefined` | Supplies MCP header values at every create, resume, recreate and restart. Header values are never stored. See [MCP](/sdk/mcp#credentials-that-change). |
| `autoRestart` | `boolean \| { maxAttempts?, backoffMs? }` | Default off. Respawns the runtime after an unexpected exit and re-opens every live thread. `true` = 5 attempts, 1 s backoff that doubles. |
| `requireCompatibleRuntime` | `boolean` | Default off. `true` throws `runtime_incompatible` for a runtime outside `SUPPORTED_RUNTIME_RANGE`. |
| `source` | `"packaged"` | Set by `resolvePackagedRuntime()`. Makes `doctor().runtime.source` report `packaged`. |

`resolvePackagedRuntime(resourcesPath, { dir?, platform?, arch? })` returns `{ binaryPath, runtimeRoot, runtimeNodeModules, source: "packaged" }` or `null`. Spread it into the options. See [Bundling](/sdk/bundling#inside-a-packaged-app).

`SUPPORTED_RUNTIME_RANGE` is the runtime range this SDK build supports. SDK 0.3.0 supports `>=1.2.81 <2.0.0`.

Runtime resolution runs in five steps: `binaryPath`, then an installed `@ade-dev/runtime-<target>` package, then the home cache, then `ade` on `PATH`, then a download. See [Bundling](/sdk/bundling).

| `providers.onChange(cb)` | Full status list on each change. Never bypasses the cache. Returns unsubscribe. |
| `models.list()` | Catalog. `providerId` must match a status entry to be selectable in chat-ui. |
| `doctor()` | Structured health check. |
| `exportThread(key)` | Transcript as JSONL. |
| `dispose()` | Stop the runtime. Idempotent. Ends in-flight turns without `error`/`done`. |

## `threads.open` options

| Option | |
|---|---|
| `provider` | `claude` \| `codex` \| `cursor` \| `droid` \| `opencode` \| `pi` |
| `model` | Catalog id (aliases resolved by the runtime). |
| `permissions` | `"always-allow"` \| `"default"` \| `ThreadPermissionPolicy`. See [Permissions](/sdk/permissions). |
| `instructions` | `string \| { mode: "append" \| "replace", text }`. A bare string means append. |
| `cwd` | Absolute path the provider runs in. Created at mode `0755`. Defaults to `<home>/personal-chats/workspaces`. |
| `settingSources` | `"none"` (default) \| `"project"` \| `"user"` \| `"all"`. |
| `reasoningEffort` | Provider-native effort token, when the model offers one. |
| `title` | Display title stored on the thread record. |
| `mcpServers` | Caller-owned servers for this thread. See [MCP](/sdk/mcp). |
| `loadUserMcpServers` | Opt the user's MCP back in. Explicit `false` ≠ omitting the field. |
| `refresh` | `{ mcpServers }`. Replaces the thread's MCP servers on a resume, so a new token or port takes effect. The one option a resume does not ignore. |

All four host-configuration options persist on the thread record, so a resume that has to recreate a lost session rebuilds the same thread.

They apply on **create only**, with one exception: `refresh.mcpServers`. A resume reads `cwd`, `instructions`, `settingSources`, `permissions`, `mcpServers` and `loadUserMcpServers` off the stored record and ignores what this call passed, logging one line per differing option. Open a different key to run under different configuration.

A **recreate** (the key is stored, but the runtime lost its session) uses the stored record first. This call's options fill only fields the record does not have. The SDK logs one line for each stored value it used.

```ts
type ThreadPermissionPolicy = {
  allowedTools?: string[];          // exact names, or a trailing `*`
  deniedTools?: string[];           // wins over allowedTools
  autoApproveMcpServers?: string[]; // same as `mcp:<server>:*`
  sandboxRoot?: string;             // absolute; containment, not a working dir
  fallback: "ask" | "deny";         // required
};
```

What a policy is worth depends on the provider and, on Claude, on `fallback`. A deny fallback removes the unnamed mutating built-ins and scopes MCP to the servers the policy names. An ask fallback relies on the Agent SDK's permission prompt. Read `thread.permissionCapability` and see [Permissions](/sdk/permissions).

## `AdeThread`

| Member | |
|---|---|
| `id` / `key` | Runtime session id and caller key. |
| `mcpCapability` | Honesty report. `null` when MCP was not requested, **or** when an older runtime omitted the report — treat the latter as unverified if you asked. |
| `send(text, opts?)` | Dispatch a turn. Resolves when accepted, not when finished. |
| `title` | The thread's title, or `null`. |
| `model` | `ThreadModelSelection` — `{ modelId, provider, model, displayName }`, or `null` before the runtime reported one. |
| `steer(text, { attachments }?)` | Mid-turn follow-up. Does not start a turn. Text or at least one attachment. |
| `interrupt()` | Stop the in-flight turn. |
| `setModel(id, opts?)` | Switch model/provider. Refused mid-turn unless `{ force: true }`. Returns the selection plus `capabilities` (the four reports for the new provider), and emits `capabilities_changed` on the `status` channel. |
| `update({ title?, reasoningEffort?, fastMode? }, { force? }?)` | Rename, or change effort or fast mode. A rename always works; the other two are refused mid-turn unless `{ force: true }`. Returns `{ title, model }`. |
| `updateMcpServers(servers)` | Replace the thread's MCP servers. Takes effect on the next turn. Returns the new `mcpCapability`. Needs runtime 1.2.81 or later. |
| `history({ limit }?)` | Envelopes in transcript order. |
| `historyPage({ beforeSequence?, limit? }?)` | One page: `{ events, hasMore, nextBeforeSequence }`. Omit `beforeSequence` for the newest page. |
| `approve(itemId, decision, responseText?)` | Answer an approval. `"accept"` \| `"accept_always"` \| `"reject"`. Throws `approval_not_found` when it is already settled, and `invalid_option` for a question-shaped request. |
| `pendingApprovals()` | Outstanding requests, so a reload can restore cards. |
| `instructionsCapability` | `{ requested, level, mode, mechanism, detail }` or `null`. |
| `settingSourcesCapability` | `{ requested, level, value, mechanism, detail }` or `null`. |
| `permissionCapability` | `{ level, mechanism, residual }` or `null`. Refreshed after `setModel`. |
| `on("event" \| "status" \| "usage", cb)` | Subscribe. Returns unsubscribe. When the runtime exits, each live thread receives `{ type: "status", turnStatus: "error", message, synthetic: true }` on `status`. |

The three capability fields are `null` when the thread requested nothing, **and** when an older runtime reported nothing. `level` is `"applied"` \| `"best-effort"` \| `"ignored"` for the two host-config reports, and `"enforced"` \| `"best-effort"` \| `"unsupported"` for the permission one.

| Field | |
|---|---|

| `sessionId`, `provider`, `model`, `title`, `status` | As the runtime reports them. |

| `modelSelection` | `ThreadModelSelection` with `displayName`, or `null`. |

## Session summary

`AgentChatSessionSummary` is the runtime's record of a tracked session. Two fields report the Codex app-server collaboration mode when a live runtime has one:

| Field | |
|---|---|
| `codexEffectiveCollaborationMode` | `"default"` \| `"plan"`. Absent when the runtime did not report a mode. |
| `codexEffectiveCollaborationModeWasCleared` | `true` when a live Codex runtime confirms there is no accepted turn mode. |

`AgentChatCodexCollaborationMode` is that `"default"` \| `"plan"` union.

## `ProviderStatus` {#providerstatus}

```ts
type ProviderStatus = {
  provider: string;
  displayName: string;
  installed: boolean;
  binaryPath: string | null;
  version: string | null;
  authenticated: boolean;
  authMethod?: string | null;
  installCommand: string | null;
  loginCommand: string | null;
  docsUrl: string | null;
  available: boolean;
  requiresConfiguration: boolean;
  modelCount: number;
  stale: boolean;
  source: "probed" | "derived";
  checkedAt: string;
  detail?: string | null;
};
```

`source` is the field to read first. On a `"derived"` record — an older runtime with no `providers.status` RPC — `installed` is `modelCount > 0`, and `binaryPath`, `version` and the three remediation fields are `null`. `stale` is true when either the probe or the model catalog behind the verdict was served from the cache rather than produced by this call. It is not a claim that the record is past the runtime's TTL: a record served from inside the TTL is stale by this definition too.

## `doctor()` {#doctor}

```ts
type DoctorReport = {
  ok: boolean;
  sdkVersion: string;
  binary: {
    path: string;
    version: string | null;
    source: "option" | "path" | "download" | "cache";
    checksumVerified: boolean;
  };
  runtime: {
    source:
      | "packaged"
      | "explicit"
      | "bundled-package"
      | "cached-download"
      | "path"
      | "downloaded"
      | "attached";
    binaryPath: string;
    version: string | null;
    runtimeRoot: string | null;
    nodeModulesPath: string | null;
    signature: { signed: boolean; authority?: string; accepted?: boolean | null } | null;
    downloadedThisSession: boolean;
    checksumVerified: boolean;
    compatibility: {
      supported: boolean;
      range: string;          // SUPPORTED_RUNTIME_RANGE
      version: string | null; // what the runtime reported
      note: string | null;    // why a version passed without a check
    };
  };
  socket: {
    path: string;
    connected: boolean;
    runtimeVersion: string | null;
    pid: number | null;
  };
  events: {
    mode: "push" | "drain" | "unavailable";
    epoch: string | null;
    gapsRecovered: number;
  };
  providers: Record<string, ProviderStatus>;
  threads: { tracked: number; live: number };
  recentErrors: Array<{ at: string; scope: string; message: string }>;
};
```

`sdkVersion` is injected at package build time from `package.json`. Compare it to `socket.runtimeVersion` when versions disagree.

`binary` is the 0.1.x view and keeps its four `source` values. `runtime` is the 0.2 view: which of the five resolution steps produced the binary, and what the OS thinks of its signature. `runtime.signature` is `null` for "not known", never for "not signed" — see [Runtime](/sdk/runtime#doctorruntime). `accepted` is Gatekeeper's verdict on the outermost `.app` that contains the runtime, and `null` when it could not be judged. `runtime.compatibility` compares the runtime version with `SUPPORTED_RUNTIME_RANGE`; see [Runtime](/sdk/runtime#version-compatibility).

## Errors

`AdeError` with `code`:

`runtime_incompatible` · `binary_not_found` · `download_failed` · `checksum_mismatch` · `spawn_failed` · `connect_failed` · `handshake_failed` · `rpc_error` · `rpc_timeout` · `transport_closed` · `protocol_error` · `thread_not_found` · `invalid_option` · `runtime_unavailable` · `approval_not_found` · `unauthorized` · `disposed`

`setModel` mid-turn without `{ force: true }` throws `invalid_option`. So does a relative or refused `cwd`, a policy with no `fallback`, a `sandboxRoot` that is not absolute, and an `approve()` naming a question-shaped request — the SDK checks those before any RPC, and the engine's own `invalid_argument:` refusals are mapped onto the same code.

`runtime_incompatible` comes from `createAdeChat({ requireCompatibleRuntime: true })` when the runtime version is outside `SUPPORTED_RUNTIME_RANGE`.

`approve()` throws `approval_not_found` when the item is already settled. `unauthorized` comes from an Electron bridge whose `authorize` hook refused the call.
