## The rest of the vocabulary

These are areas rather than foundations. You will meet them as you work.

| Term | What it means |
|---|---|
| **CTO** | A persistent project-level agent with durable memory, used for planning and delegation. [CTO](/cto/overview) |
| **Proof** | Intentional evidence — screenshots, recordings, traces — tied to a chat, lane, PR, or issue. [Proof](/computer-use/proofs) |
| **PR flow** | A lane linked to its GitHub pull request: diff, CI, comments, merge. [Pull requests](/tools/pull-requests) |
| **History** | The searchable project record of sessions, commits, PR events, and checkpoints. [History](/tools/history) |
| **Automations** | Event- or schedule-triggered rules that start work without you. [Automations](/tools/automations) |

## Local project state

ADE stores project data in `.ade/` inside your repository — the local database, worktrees, artifacts, caches, and machine-specific state. Keep it out of Git unless a page explicitly says a file is safe to share.

<Tip>
If you only read one more page, read [Lanes](/concepts/lanes). Almost every surprise in ADE is really a question about which worktree you are in.
</Tip>
