## Frost

Frost is built on a narrow band of blue-grey: the six surfaces sit close together, so panels separate by edge rather than by brightness. Every hue is desaturated to match, which keeps a full-colour diff from shouting. Inspired by the northern-palette tradition; the values are ours.

Sets all 86 spec tokens in both light and dark. Preview it from the Marketplace without installing, then use it when you are ready.
