Spectre is the loud theme: a slate-violet ground under fully saturated pink, cyan, lime and purple. Chrome stays dark and calm so the colour lands where it matters — syntax, diffs, the rail and charts. Inspired by the classic vampire-palette tradition; the values are ours.
