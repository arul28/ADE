## Kiln

Kiln is warm all the way down: the greys are brown, the greens are olive, and the accent is fired orange. High-saturation hues on a low-saturation ground, which is why a busy diff still separates cleanly. Inspired by the classic retro-terminal palettes; the values are ours.

Sets all 86 spec tokens in both light and dark. Preview it from the Marketplace without installing, then use it when you are ready.
