## Phosphor

The green-screen idea, done properly. The chrome is phosphor — green-black wells, green rails, a green cursor — but the code is not: keywords, strings, numbers and types each get their own hue, so a file still reads like a file. That contrast between monochrome chrome and full-colour code is the whole point.

Sets all 86 spec tokens in both light and dark. Preview it from the Marketplace without installing, then use it when you are ready.
