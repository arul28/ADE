## Mocha

Mocha runs on a lavender-tinted grey rather than a neutral one, and every hue is a pastel of the same lightness — so nothing in a syntax-coloured file jumps. It pairs with Latte, which is the same idea in daylight. Inspired by the pastel-palette tradition; the values are ours.

Sets all 86 spec tokens in both light and dark. Preview it from the Marketplace without installing, then use it when you are ready.
