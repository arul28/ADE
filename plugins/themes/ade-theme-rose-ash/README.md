## Rose Ash

Rose Ash is muted on purpose: ash-violet surfaces, dusty rose and gold hues, nothing at full saturation. The result is a palette with real colour that still reads as neutral after an hour. Its dawn mode is warm rather than white. Inspired by the muted-rose palette tradition; the values are ours.
