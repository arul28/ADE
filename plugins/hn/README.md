# Hacker News

A chat-header reader for Hacker News. The orange **HN** button opens the
Hacker News tab immediately (stories keep loading in the background). Its
dropdown switches between Top, New, and Ask. The same panel also sits in the
Work tools rail. Click a story to open it in the browser. Mark-as-read is
stored in a synced collection so other devices (including the phone) see it.

Talks to `hacker-news.firebaseio.com`. The button colour is `#E65C00` — HN
orange darkened just enough to stay readable on both ADE themes. Classic
`#FF6600` fails the host contrast gate on light backgrounds.
