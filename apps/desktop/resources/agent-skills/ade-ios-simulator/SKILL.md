# Moved to ade-apple

The iOS simulator skill is now **ade-apple**. Read
`apps/desktop/resources/agent-skills/ade-apple/SKILL.md` (or `ade skill show ade-apple --text`).

The CLI group is `ade apple`. `ade ios-sim` still works as an alias for one
minor release and prints a deprecation line to stderr.
