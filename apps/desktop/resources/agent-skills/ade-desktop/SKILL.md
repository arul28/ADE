# Moved to ade-computer-use

The Mac Desktop skill is now **ade-computer-use**, the one entry point for
computer use in ADE. Read
`apps/desktop/resources/agent-skills/ade-computer-use/SKILL.md` (or
`ade skill show ade-computer-use --text`).

The CLI group is unchanged: `ade mac-desktop`. Note that `ade desktop` is a
different command — it launches the ADE desktop app.
