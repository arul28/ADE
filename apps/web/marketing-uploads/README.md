# Marketing uploads

Put raw files here. Claude compresses them and moves them into `public/` for the site.
Do not worry about file size or format. Any PNG, JPG, MOV, or MP4 is fine.

1. `1-hero-devices` — the same view on three devices, taken at the same moment.
2. `2-wall-clips` — short clips for the wall of GIFs. One feature per clip.
3. `3-feature-cards` — one picture or clip for each of the four main cards.
4. `4-link-preview-later` — leave empty for now.
